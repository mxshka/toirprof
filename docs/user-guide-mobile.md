# Руководство пользователя. Мобильный клиент бригады

Приложение для Android — для слесарей и электриков ремонтной бригады, которые
работают у оборудования, а не за компьютером. Всё, что сделано в телефоне,
сразу видно мастеру в настольном клиенте и руководителю в веб-версии: данные
идут через тот же сервер.

Интерфейс рассчитан на одну руку: крупные кнопки высотой не меньше 52 точек,
главные действия внизу экрана, нижняя панель из четырёх вкладок.

---

## 1. Установка

1. Скопируйте `ToirProf-mobile.apk` на телефон (кабель, мессенджер, флешка).
2. Откройте файл и разрешите установку из этого источника.
3. Значок «ТОиР-Проф» появится среди приложений. Нужен Android 6.0 или новее.

Сервер и телефон должны быть в одной сети (Wi-Fi площадки). На компьютере
API запускается профилем `lan`: `dotnet run --project src/api --launch-profile lan`.

## 2. Вход

| Поле | Что ввести |
|------|------------|
| Логин или email | учётная запись из системы, например `master` |
| Пароль | пароль этой записи |
| Сервер | `http://<IP компьютера>:5080`; в эмуляторе — `http://10.0.2.2:5080` |

Отметка «Входить по отпечатку» включает **биометрический вход**: в следующий
раз приложение само предложит приложить палец (или лицо — как настроено в
телефоне). Пароль при этом в телефоне не хранится: отпечаток открывает
сохранённый сеанс, пока он не истёк (12 часов). Включить и выключить отпечаток
можно на вкладке «Справка».

Кнопка «Работать без сети» открывает заявки из памяти телефона, если сервер
недоступен, — например, в подвале насосной.

## 3. Вкладка «Заявки»

Список заявок бригады, в которую входит пользователь: назначенные, в работе,
ожидающие материалов. Сверху — сводка (сколько активных, в работе,
критических) и время последнего обновления.

- цветная полоса слева — приоритет (красный — критический, жёлтый — высокий);
- красная подпись «просрочено» — плановый срок прошёл;
- «ждёт отправки» — действие сделано без связи и стоит в очереди.

Отметка «Показать выполненные» добавляет закрытые за последние 7 дней.

## 4. Карточка заявки: работа в одно нажатие

| Кнопка | Что происходит |
|--------|----------------|
| **Начать работы** | статус «В работе», время фактического начала ставит сервер |
| **Завершить и отправить отчёт** | открывает короткую форму: причина неисправности (обязательно) и что сделано; «Завершить» ставит статус «Выполнена» |
| **Фото «до»** / **Фото «после»** | открывается камера; снимок сжимается до 1280 точек и прикрепляется к заявке вместе с координатами |
| Строка оборудования | паспорт, типовые неисправности и инструкции ТО |

Мастер получает уведомление о завершении и видит фото в карточке заявки.

## 5. Вкладка «QR-код»

На оборудовании наклеен QR-код с инвентарным номером (наклейки печатаются из
`docs/qr-labels.html`). «Сканировать QR-код» открывает камеру, после снимка
приложение распознаёт код и показывает:

- паспорт: производитель, модель, заводской номер, место установки;
- активные заявки по этой единице;
- типовые неисправности — что и как часто ломалось;
- ближайшие ТО с инструкцией по каждому виду работ.

Если код повреждён, номер можно ввести вручную и нажать «Найти».
Кнопка «Сообщить о неисправности» открывает новую заявку на эту единицу.

## 6. Вкладка «Новая»: сообщить о неисправности

Оборудование выбирается из списка или QR-кодом. Тип — аварийная или
инициативная, для аварийной обязательна причина. **Координаты подставляются
автоматически** по GPS телефона при открытии формы — мастер видит, где
именно была сделана заявка. «Сфотографировать дефект» прикладывает фото «до».

- «Отправить заявку» — заявка сразу появляется у мастера;
- «Сохранить черновик» — заявка остаётся в телефоне, её можно дополнить
  («Изменить») и отправить позже.

## 7. Работа без связи

Если сервер недоступен, приложение не теряет действия:

1. Начало и завершение работ, фото и новые заявки складываются в очередь.
   В шапке горит «Нет связи · в очереди N».
2. Заявки, оборудование и справочник берутся из памяти телефона.
3. Как только связь появилась, очередь отправляется сама (проверка раз в
   20 секунд) или по кнопке «Обновить» на вкладке «Справка».
4. Фото к заявке, созданной без связи, отправляется сразу после самой заявки.

Если сервер отклонил действие (например, мастер уже отменил заявку), приложение
покажет уведомление с причиной.

## 8. Уведомления

Раз в 20 секунд приложение спрашивает у сервера новые события (назначение
заявки на бригаду, смена статуса, просрочка) и показывает их в шторке
телефона. Сервисы Google для этого не нужны — работает в закрытой сети
площадки. На Android 13 и новее при первом событии телефон спросит разрешение
на уведомления.

## 9. Вкладка «Справка»

Профиль (ФИО, роль, бригада), адрес сервера, переключатель входа по отпечатку,
список действий, ждущих отправки, и инструкции по видам ТО с периодичностью.
«Выйти» удаляет сеанс из телефона; черновики остаются.

## 10. Частые вопросы

| Проблема | Что сделать |
|----------|-------------|
| «Нет связи» при входе | проверьте Wi-Fi и адрес сервера; на компьютере API должен быть запущен профилем `lan`, порт 5080 открыт в брандмауэре |
| «Сеанс истёк» | войдите паролем ещё раз |
| QR не распознаётся | снимайте ближе, без бликов; или введите номер вручную |
| Нет координат | разрешите приложению доступ к местоположению в настройках телефона |
| Не приходят уведомления | разрешите уведомления для «ТОиР-Проф» в настройках телефона |
