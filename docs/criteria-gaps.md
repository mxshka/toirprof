# Сверка с критериями оценки: что ещё не закрыто

Сверка решения с листом `05-Критерии-оценки.xlsx` (около 220 аспектов) от
19.11.2026. Всё, чего нет в списке ниже, реализовано и проверено: база
(20/20 в `db/verify.sql`), сборка всех проектов, 5/5 модульных тестов,
сквозной сценарий API (50/50 в `tools/smoke.ps1`), все страницы web без
ошибок в консоли.

В скобках — сколько баллов снимается за аспект по листу критериев
(максимальный вычет). Внутри каждого раздела пункты идут от простых к
сложным.
